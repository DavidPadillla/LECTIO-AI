LECTIO-AI — INFORME DE ENDPOINTS DE LA API REST

Fuente: app/api/routes.py, app/api/schemas.py y handlers ejecutados con el
modelo e informes locales disponibles.

Los ejemplos son respuestas obtenidas localmente del modelo/reportes guardados.
No se consultó ni escribió en Neon. Los identificadores UUID de libros fueron
anonimizados como "book-demo-001". Las listas se reducen a un elemento
representativo; los nombres de campos y tipos corresponden a la respuesta real.

========================================================================
1. GET /health
========================================================================

Parámetros: ninguno.

Ejemplo JSON:
{
  "status": "ok"
}

Campos:
- status: string

- per_book_errors: array de objetos:
  - book_id: string
  - test_periods: integer
  - mlp_mae: number

5. GET /recommendations
========================================================================

Parámetro:
- limit: integer, opcional; predeterminado 200, mínimo 1 y máximo 500.

Ejemplo JSON (limit=1):
{
  "data_type": "sintetico_demostrativo",
  "horizon_days": 30,
  "safety_margin": 0.2,
  "recommendations": [
    {
      "book_id": "book-demo-001",
      "category": "Novelas",
      "data_type": "sintetico_demostrativo",
      "historical_demand": 10,
      "forecast_demand_30_days": 2.53,
      "stock_available": 1,
      "reserved_units": 2,
      "total_inventory": 3,
      "risk_level": "ALTO",
      "recommended_replenishment": 3,
      "safety_margin": 0.2,
      "formula": "max(0, ceil(demanda_pronosticada_30_dias * (1 + margen_seguridad) - stock_disponible))"
    }
  ]
}

Campos:
- data_type: string
- horizon_days: integer
- safety_margin: number
- recommendations: array de objetos con:
  - book_id: string
  - category: string
  - data_type: string
  - historical_demand: integer
  - forecast_demand_30_days: number o null
  - stock_available: integer
  - reserved_units: integer
  - total_inventory: integer
  - risk_level: string; valores admitidos: ALTO, MEDIO, BAJO o
    DATOS_INSUFICIENTES
  - recommended_replenishment: integer
  - safety_margin: number
  - formula: string

    insufficient_activity_books, non_demo_books_excluded: integer

    (integer), activity_level (string)

    (integer)
  - monthly_demand: array de objetos con month (string), demand (integer)
  - weekday_demand: array de objetos con weekday (string), demand (integer)
  - trend: object con direction (string), change_percent (number o null) y
    method (string)
  - seasonality: object con assessed (boolean) y finding (string)

========================================================================
NOTAS DE PARÁMETROS Y ERRORES
========================================================================

- /health, /model/status, /metrics y /analytics no reciben parámetros.
- /predictions y /recommendations admiten limit (integer entre 1 y 500,
  predeterminado 200).
- /predictions/{book_id} y /recommendations/{book_id} reciben book_id como
  parámetro de ruta de tipo string.
- Si no existe un modelo, /model/status responde normalmente con trained=false
  y campos opcionales nulos. /predictions, /recommendations y /metrics
  responden HTTP 503 cuando no se puede cargar el modelo.
- /analytics responde HTTP 503 si todavía no existe analytics.json.
- Los dos endpoints por book_id responden HTTP 404 cuando el libro no existe.
- Los ejemplos corresponden a resultados sintéticos demostrativos guardados
  localmente, no a una consulta actual a Neon.
